# CtaBand

The closing band. One per page. `accent` variant is loud — reserve for high-conversion landing pages where the rest of the page is dark.

```jsx
<CtaBand
  overline="diagnóstico inicial"
  headline="Pronto para tirar os gargalos da sua operação de vendas?"
  subhead="Nosso diagnóstico dura 30 minutos e mapeia as 3 principais automações para sua equipe."
  primaryCta={{ label: 'Agendar diagnóstico', href: '#contato' }}
  secondaryCta={{ label: 'Ver metodologia', href: '#metodo' }}
/>
```
