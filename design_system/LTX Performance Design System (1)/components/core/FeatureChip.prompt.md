# FeatureChip

The brand's signature icon container: `40×40`, Cinza Grafite tile, Verde Neon icon at 1.5 stroke. Use at the top-left of every feature card.

```jsx
<FeatureChip icon={<Target />} />
```

Pair with Lucide icons only (CDN: `https://unpkg.com/lucide-static@latest/icons/<name>.svg`). Keep size consistent across a single page.
