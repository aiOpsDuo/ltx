# FeatureCard

The "Por que LTX" grid card.

```jsx
<FeatureCard
  icon={<Workflow />}
  title="Triagem automática de leads"
  body="Conectamos formulários ao seu Pipedrive e disparamos a primeira mensagem em 3 segundos."
/>
```

Keep grids to 3 cards on desktop, 1 column on mobile. Every card needs an icon — the chip is the brand's vocabulary.
