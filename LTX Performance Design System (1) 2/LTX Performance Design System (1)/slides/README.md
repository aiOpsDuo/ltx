# LTX Performance — slide templates

Seven 16:9 (1280×720) slides covering the obligatory deck types defined in `design-system/applications/presentations.md`. They use the brand tokens via `styles.css` so swapping a token cascades to every slide.

## Files
- `01-title.html` — capa with `lockup-stacked` + project title.
- `02-section-divider.html` — Verde Neon Space Mono headline against the canvas.
- `03-big-stat.html` — one giant number with source.
- `04-comparison.html` — three FeatureChip columns.
- `05-timeline.html` — three-step methodology with hairlines.
- `06-quote.html` — case study with outcome card.
- `07-close.html` — closing tagline + contact.

## Rules carried from `presentations.md`
- Max 40 words per slide.
- Footer marca + page number always present (Sora 11px, `#696F6D`).
- No transitions beyond fade. No 3D, no spin, no typewriter.
