# Badge

Small status pill. Never used as an action — for that, see `Button`.

```jsx
<Badge tone="brand" uppercase>lógica em movimento</Badge>
<Badge tone="success">Sincronizado</Badge>
<Badge tone="outline">Pipedrive</Badge>
```

The `uppercase` flag is the brand's overline/kicker treatment — Space Mono, +0.06em tracking. Use it only for section overlines, never to shout in a list.
