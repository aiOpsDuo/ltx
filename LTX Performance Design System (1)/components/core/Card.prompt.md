# Card

Surface container on the dark canvas. Flat by default — elevation only on hover.

```jsx
<Card hoverable>
  <CardHeader>
    <Badge tone="brand" uppercase>fluxo automático</Badge>
    <CardTitle>Triagem de leads em 3 segundos</CardTitle>
  </CardHeader>
  <CardBody>
    Conectamos seus formulários ao Pipedrive…
  </CardBody>
</Card>
```

## Variants
- `surface` (default) — `#1A1F26` with hairline.
- `ghost` — transparent with hairline (used inside a darker section).
- `accent` — Verde Neon left border (use **once** per page, on the featured plan / pillar).
