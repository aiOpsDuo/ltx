# Stat

Big number in Verde Neon. Anchors case studies and stat bars.

```jsx
<Stat
  value="34%"
  label="redução de CAC em 8 semanas"
  source="Hospital São Lucas, Porto Alegre"
/>
```

## Rules
- Always cite a real source. No "studies show" placeholders.
- Keep the number short — "40%" not "40.7%". Round.
- Never put more than 3 stats in one row.
